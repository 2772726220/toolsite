摩斯电码是什么？

摩斯电码用点和划的组合表示字母和数字，是最早的远程通讯编码，至今在业余无线电中仍在使用。

这个工具能做什么？

文字一键转摩斯电码（. 和 -），摩斯电码一键还原文字，还支持带音效的播放学习。

常见问题

支持哪些字符？

支持 A-Z、0-9 及常见标点。

能播放心跳声吗？

可以，点击播放以音效节奏听摩斯码。

数据会上传吗？

不会，本地转换。

字母间 3 个间隔，单词间 7 个间隔，标准格式。
