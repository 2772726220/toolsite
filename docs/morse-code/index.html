摩斯电码是什么？

摩斯电码用点和划的组合表示字母和数字，是最早的远程通讯编码，至今在业余无线电中仍在使用。

这个工具能做什么？

文字一键转摩斯电码（. 和 -），摩斯电码一键还原文字，还支持带音效的播放学习。
