度分秒怎么转十进制度？

十进制度 = 度 + 分/60 + 秒/3600，反向则整数部分取度、小数乘 60 取分、再乘 60 取秒。

弧度是什么？

弧度是国际标准角度单位，1 圆周 = 2π 弧度 ≈ 6.2832，编程语言三角函数默认用弧度。
