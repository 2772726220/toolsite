常见问题

类型怎么推断？

数字推断为 int64（含小数则为 float64），字符串 string，布尔 bool，数组生成切片，对象递归生成结构体。

json tag 是什么？

用于 encoding/json 序列化时映射 JSON 字段名，保证字段名与原始 JSON 一致。

会处理空值吗？

可选：勾选 omitempty 后生成 `json:"name,omitempty"` 标签。

需要联网吗？
