cron 的日与周字段冲突怎么办？

标准 crontab 中当日与周同时受限时按“或”逻辑匹配（任一满足即执行）。本工具严格遵循该语义，如 0 0 13 * 5 表示每月 13 号或每周五执行。

x 月没有 31 号怎么办？

月份只有 30 天的日子不会匹配 31 号，属于正常现象，查找会跳过；日期永远以“所在那个月”的有效天数为准。

常见问题

支持哪些 cron 写法？

支持 * 任意、1-5 区间、*/15 步长、1,3,5 列表、1-30/5 带步长区间；周字段支持 0-7，7 等价于 0（周日）。

结果精度如何？

按分钟级精确匹配，会列出从小到大最近的 N 次（默认 5 次、可选 3/10），并显示距起始时刻的天时分。

存在无法执行的情况吗？

有。例如 2 月 29 日这类极稀疏表达式在兜底搜索窗口（约 4 年）内找不到时会明确提示，而不是静默出错。
