Base64 是什么？

Base64 是一种用 64 个可打印字符表示二进制数据的编码方式，常用于在文本协议中传输图片、文件、密钥等二进制数据，是开发者常用工具。

这个工具能做什么？

文本转 Base64、Base64 转回文本、文件转 Base64（用于嵌入图片等），支持中文 UTF-8 和 URL Safe 模式，全部实时处理。

常见问题

Base64 能加密吗？

不能，Base64 只是编码，可逆且无密钥，不用于保密。

支持中文吗？

支持，按 UTF-8 编码，中文正常编码解码不乱码。

URL Safe 模式是什么？

将 +、/、= 换成 URL 安全字符，用于在 URL 参数中传输 Base64 数据。

文件怎么转 Base64？

选择文件后自动转成 Base64 文本，常用于将小图片直接嵌入 HTML/CSS 中。
