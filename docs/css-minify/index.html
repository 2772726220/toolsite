为什么要压缩 CSS？

CSS 文件越小加载越快，去除注释和空白能明显减小体积，加快网页加载。

这个工具能做什么？

压缩（去注释空白）和格式化（美化还原）双向处理，实时统计压缩前后大小。

常见问题

压缩会破坏样式吗？

不会，只移除注释和空白，语义不变。

可以，切换格式化模式即可美化。

只支持标准 CSS，SCSS 需先编译。
