什么是数值积分？

对被积函数在区间上按离散点求和的近似积分方法，本工具采用复化辛普森公式，精度远高于梯形法。

支持哪些函数？

支持 + - * / ^、( )、sin、cos、tan、exp、ln、log10、abs、sqrt，幂运算 ^ 右结合。

常见问题

结果有多准？

区间数 n 默认 1000，对光滑函数误差极小；如 x² 在 [0,3] 的结果是 9，sin(x) 在 [0,π] 是 2。

n 是奇数会怎样？

辛普森法要求偶数区间，工具会自动把奇数加一。

函数含非法字符会被拦截吗？

会。输入先校验只允许数字、运算符与白名单函数名。
