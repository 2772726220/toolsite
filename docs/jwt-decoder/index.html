什么是 JWT？

JWT（JSON Web Token）是登录鉴权常用的令牌格式，由 Header.Payload.Signature 三部分 Base64Url 编码组成，本工具帮你快速查看内容。

解析安全吗？

完全在浏览器本地 Base64 解码，Token 不会上传到任何服务器。工具不校验签名，仅用于查看内容。

常见问题

能验证签名吗？

本工具只解码展示内容，不验证签名。生产环境请使用官方库校验。

过期时间怎么看？

Payload 中的 exp 字段是 Unix 秒时间戳，工具会换算成可读日期并提示是否已过期。

支持 HS256 密钥解密吗？

HS256 是签名不是加密，Payload 本身可读；如需验证签名请使用专用库。
