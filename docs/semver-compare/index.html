什么是语义化版本号？

SemVer 采用 主版本.次版本.修订版（major.minor.patch）结构，如 1.2.3。预发布版本用 -rc.1、-alpha 等后缀标识，排序时低于正式版；构建元数据 +build 不参与大小比较。

为什么版本排序不能按字符串？

1.10.0 字符串小于 1.9.1，但语义上更大。本工具按 SemVer 规则逐段数值比较，确保版本排序与包管理器的行为一致。

常见问题

预发布版本怎么比较？

-alpha.1 低于 -beta，-beta 低于正式版；数字标识 < 字母标识（如 alpha.1 < alpha.beta），无前导零的数字按数值比较。

1.0.0+build 和 1.0.0 相等吗？

相等。build 元数据仅用于标识，不参与版本大小比较。

支持哪些格式？

支持标准的 X.Y.Z 以及带 -预发布 和 +构建元数据的完整格式；v1.2.3、01.2.3 等非规范格式会被判定为无效。

版本 +1 有什么用？

发布新版本时常用：选 major 会进位主版本并清零次版本与修订版，minor 只清零修订版，patch 只加 1。
