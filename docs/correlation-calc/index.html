三种相关系数区别？

皮尔逊：线性关系、连续变量、正态分布；斯皮尔曼：单调关系、秩序/非正态；肯德尔：小样本、有序分类、抗干扰强。

p值代表什么？

原假设（无相关）下出现当前或更极端结果的概率，p<0.05 通常认为相关性显著。
