CSS Grid 有什么优势？
Grid 是二维布局系统，比 Flexbox 更适合复杂页面布局，行列控制精确，代码简洁。
怎么用生成的代码？
复制生成的 CSS 到样式表，HTML 按区域名添加类名即可。支持命名网格区域，语义化更强。

    
常见问题

    
支持响应式断点吗？
支持，可为不同断点设置不同行列模板。
生成的代码兼容性如何？
CSS Grid 在现代浏览器（Chrome 57+、Firefox 52+、Safari 10+、Edge 16+）完美支持。
可以导出 SCSS/Less 吗？
目前仅输出原生 CSS，可手动转换为预处理器语法。
支持子网格吗？
当前版本生成基础 Grid，子网格需手动扩展。
