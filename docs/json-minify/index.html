JSON 压缩有什么好处？

压缩后移除所有多余空白和换行，体积可减小 30%-70%，便于放入 URL 参数、浏览器书签或在需要单行 JSON 的接口中粘贴。

支持哪些输出格式？

支持纯文本、Base64、URL 编码三种输出，Base64 适合嵌入小程序/App 配置，URL 编码适合直接放进 GET 请求参数。

常见问题

会损坏原数据吗？

不会，压缩前后是等价的 JSON，任何阶段都可解析回相同对象；本工具在压缩前会先校验 JSON 合法性，非法输入会提示错误位置。

能恢复成多行吗？

可以，切换美化排版模式即可输出带缩进的多行 JSON，无需重传数据。

压缩是本地完成的吗？

完全本地完成，JSON 不会被上传到任何服务器。

支持压缩数组和大对象吗？

支持，任意合法 JSON 均可压缩，无大小限制；超大内容建议复制纯文本输出。
