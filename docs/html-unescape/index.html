什么是 HTML 实体？

HTML 源码里 <、>、& 等字符必须转义为实体（如 <、>、&），否则会被误当成标签或截断，页面显示前再把实体解码回原字符。

支持哪些编码形式？

三种都支持：命名字符实体（&、<、>、"、 、© 等 20 个常用实体）、十进制数字引用（A → A）、十六进制数字引用（B → B）。

未知实体怎么处理？

未收录的命名字体会原样保留，避免误替换；嵌套的实体（如 &amp;）会一层层解开，先得到 &，再解为 &。

常见问题

数字引用支持中文吗？

支持，像 中 这样的 Unicode 码点可直接解码为对应字符（本例为「中」）。

输出结果会再转义吗？

结果框会做安全转义后再显示，避免把解码出的 < > 当作真实标签渲染。

数据会上传吗？

不会，解码处理全部在浏览器本地完成。
