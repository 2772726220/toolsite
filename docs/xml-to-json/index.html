转换规则是什么样的？

采用常见约定：元素属性变成 @属性名 键，纯文本放在 #text，同名同级子节点自动合并为数组，标签名作为最外层根键。

支持哪些 XML 特性？

支持属性和实体、CDATA、注释、XML 声明与 DOCTYPE 跳过，嵌套任意深度；对未闭合标签、闭合不匹配等给出明确错误。

常见问题

属性和子节点并存时怎么处理？

属性以 @ 开头与子节点并列存放；如果元素同时有文本和非空白子节点，文本会放进 #text 键。

重复的同名标签会覆盖吗？

不会。同一父节点下重复出现的同名标签会合并为 JSON 数组（出现一次则直接是对象）。

转换在本地还是服务器？

完全在浏览器本地完成，内容不会上传，适合处理含敏感数据的 XML。
