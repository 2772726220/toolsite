#生命游戏#元胞#演化

什么是康威生命游戏？

康威生命游戏是一个元胞自动机：每个格子依据邻居数量演化——存活细胞有 2 或 3 个活邻居时存活，否则死亡；死亡细胞恰有 3 个活邻居时复活。规则极简却能量现复杂图案。

怎么玩？

设置棋盘宽高与随机种子后点「随机生成」铺满细胞，再不断点「演化一步」观察细胞群的诞生、存活与消亡。边界采用环绕相连的环形棋盘规则。

能看到什么现象？

稳定静物、周期振荡的振子（如摆动陀螺）、沿对角线移动的滑翔机（glider）等经典图案会在演化中不断出现，适合直观感受「涌现」现象。

常见问题

棋盘尺寸范围是多少？

宽高均支持 4-64，默认 16×16；细胞越密、演化越容易出现有趣的图案。

随机种子有什么用？

相同的宽高与种子会生成完全相同的初始图案；改变种子得到不同的随机开局。

支持自动播放吗？

当前为单步演化，可连续点击「演化一步」逐步观察。
