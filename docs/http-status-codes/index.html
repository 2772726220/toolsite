HTTP 状态码有哪几类？

HTTP 状态码分为五类：1xx 信息提示、2xx 成功、3xx 重定向、4xx 客户端错误、5xx 服务器错误。掌握常见状态码能帮助你快速定位接口或网页问题。

最常见的状态码有哪些？

200 成功、301/302 重定向、400 请求错误、401 未认证、403 无权限、404 不存在、429 请求过多、500 服务器内部错误、502 网关错误、503 服务不可用。

常见问题

404 和 403 有什么区别？

403 表示服务器理解请求但拒绝访问（权限不足）；404 表示请求的资源不存在。

500 和 502 有什么区别？

500 是服务器内部错误（代码或配置问题）；502 是网关/代理收到了上游服务器的无效响应。

301 和 302 有什么区别？

301 是永久重定向，搜索引擎会更新索引；302 是临时重定向，URL 不变更。

429 是什么错误？

429 Too Many Requests，请求过于频繁被限流，通常配合 Retry-After 头使用。
