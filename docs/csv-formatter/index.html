CSV 里的引号要注意什么？

字段内含逗号或换行时需要整体加双引号包裹，字段内的双引号写作两个引号（""）转义。本工具正确解析这些情况，避免列错位。

可以转成哪些格式？

支持列对齐美化（对齐空格）、RFC4180 标准引号、Tab 分隔（TSV）以及 MySQL 风格的 INSERT 语句四种输出。

常见问题

分隔符只能识别逗号吗？

默认自动检测逗号/分号/Tab，也可手动指定。检测只统计前 2000 字符，避免超长内容拖慢速度。

解析后可以直接看表格吗？

可以，输出区下方会渲染前 200 行的表格预览，方便核对列名与内容是否对齐。

转 SQL 时引号怎么处理？

字符串字段统一用单引号包裹并将内部单引号转义为 ''，纯数字字段不加引号，可直接执行。
