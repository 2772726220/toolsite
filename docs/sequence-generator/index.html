什么是等差数列？

相邻两项之差恒定的数列，如 2,4,6,8…，本工具可自定义首项与公差生成任意长度。

斐波那契数列是什么？

从第三项起每项等于前两项之和：0,1,1,2,3,5,8…，在自然界与算法中广泛出现。
