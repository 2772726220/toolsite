判别式有什么用？

判别式 Δ=b²-4ac 决定根的情况：Δ>0 两个不等实根，Δ=0 一个重根，Δ<0 两个共轭复根。

二次方程怎么求根？

使用求根公式 x=(-b±√Δ)/2a。本工具同时输出顶点坐标 (-b/2a, c-b²/4a)，方便直接用于画抛物线。

常见问题

a 可以为 0 吗？

不能。a=0 时方程退化为一次方程，不是二次方程，工具会提示错误。

判别式为负会怎样？

方程没有实数根，但有一对共轭复数根，本工具以 a+bi 形式显示。

支持小数或分数吗？

支持小数输入（如 -1.5）。结果为小数时会自动化简显示。
