ICO 图标有什么用？

ICO 是 Windows 和网站 favicon 使用的标准图标格式。网站 favicon 显示在浏览器标签页、收藏夹里，ICO 文件可以包含多种尺寸，保证不同场景下清晰显示。

怎么把图片转成 ICO？

上传图片后选择目标尺寸（如 32x32 用于网站 favicon，256x256 用于高分辨率场景），点击转换即可下载 ICO 文件，全程在浏览器本地完成。

常见问题

图片转 ICO 会丢失质量吗？

ICO 使用无损压缩存储，转换不会丢失质量。建议源图分辨率不低于目标尺寸的两倍。

我的图片会上传吗？

不会，整个转换在浏览器本地完成，图片不会上传到任何服务器。

网站 favicon 应该用多大尺寸？

通常使用 32x32 或 48x48 即可，兼容性最好；想要更高清晰度可以生成 256x256。

支持透明背景吗？

支持。PNG 的透明通道会完整保留在 ICO 中，适合制作带透明底的图标。
