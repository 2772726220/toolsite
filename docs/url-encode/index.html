为什么要 URL 编码？

URL 中不允许出现中文和部分特殊字符，需转为 %XX 百分号编码才能在浏览器和接口中传输。

支持哪些选项？

可切换空格编码为 %20 或 +（表单格式），支持一键编码/解码。

常见问题

中文会被转成什么？

转成以 % 开头的 UTF-8 十六进制字节，如「中」转成 %E4%B8%AD。

能解码吗？

可以，粘贴编码串一键还原为原文。

空格怎么处理？

提供 %20 与 + 两种编码方式切换。

数据会上传吗？

不会，本地处理。
