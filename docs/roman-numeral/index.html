罗马数字怎么读？

用 I、V、X、L、C、D、M 表示 1/5/10/50/100/500/1000，小数字在左为减、在右为加，如 IV=4、VI=6。

支持最大多少？

标准罗马数字规范支持 1-3999，更大的数需要扩展符号。
