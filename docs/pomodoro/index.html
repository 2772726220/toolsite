什么是番茄工作法？

把时间切成 25 分钟专注块，每块中间 5 分钟休息，完成 4 个番茄后长休。短时高专注比长时间硬扛更高效。

适合谁用？

学生复习、程序员写代码、写作者赶稿，任何容易被打断的深度工作场景。

常见问题

可以自定义时长吗？

可以，专注/短休/长休时长都可设置并记忆。

到点怎么提醒？

浏览器发出提示音并弹出提示文字。

番茄数会保留吗？

当天计数保存在本地。

后台能用吗？

浏览器标签需保持打开，计时依赖标签页运行。
