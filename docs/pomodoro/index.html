什么是番茄工作法？

把时间切成 25 分钟专注块，每块中间 5 分钟休息，完成 4 个番茄后长休。短时高专注比长时间硬扛更高效。

适合谁用？

学生复习、程序员写代码、写作者赶稿，任何容易被打断的深度工作场景。
