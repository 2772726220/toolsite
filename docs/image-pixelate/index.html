像素化和马赛克有什么区别？

马赛克用于打码遮挡局部，像素化则是把整张图转换成低分辨率像素风格，形成复古游戏画风，常用于头像、封面等场景。

像素化后还能还原吗？

像素化是有损转换，信息已丢失，无法还原原图。本工具仅在浏览器本地处理，原图不会上传。

常见问题

支持什么格式？

支持 JPG、PNG、WebP。透明底 PNG 像素化后仍保留透明通道。

图片会上传吗？

不会，处理完全在浏览器本地完成。

像素块越大越像素风吗？

是的，像素块越大画面越抽象复古，建议从 8-12 开始调节。
