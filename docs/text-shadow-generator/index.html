文字阴影预览

text-shadow 语法是什么？

CSS 的 text-shadow 由水平偏移、垂直偏移、模糊半径和颜色四部分组成，例如 text-shadow: 2px 3px 4px rgba(0,0,0,0.5);。偏移越大投影越远、模糊越大边缘越柔和。

怎么设计好看的文字阴影？

除了经典的黑灰投影，可以尝试彩色阴影、与背景同色系的更深色，或调低不透明度形成柔和光晕。工具实时预览，调整偏移、模糊与颜色立即可见。

颜色和不透明度怎么控制？

用取色器选择十六进制颜色，再用 0-1 的不透明度滑块控制透明程度，工具会把 3 位/6 位十六进制统一换算成 rgba 形式输出。

常见问题

偏移与模糊的单位是什么？

水平偏移、垂直偏移与模糊半径均以 px 像素为单位并保留一位小数，非数字输入会自动按 0 处理。

颜色怎么输入？

通过取色器可选择任意颜色，内部支持 3 位（如 #f00）与 6 位（如 #ff0000）十六进制，非法颜色会提示「无效的颜色值」。
