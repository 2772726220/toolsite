什么是色阶？

把一种颜色向白色混合得到浅色（tint），向黑色混合得到深色（shade），中间的连续变化就是色阶，UI 设计中常用来做 hover 状态、进度条等。

互补色怎么用？

互补色是色轮上相对的颜色（如蓝↔橙），用于强调和对比。

常见问题

可以复制某个色阶吗？

点击任意色块即可复制对应 HEX 色值。
