怎么使用？

直接从 Excel/WPS 复制表格区域粘贴进来，或用逗号/制表符分隔粘贴，选择对齐方式后点击转换即可。

支持什么分隔符？

支持制表符（Tab）、逗号、分号、竖线等常见分隔符，也可自定义。

常见问题

转出来的表格能在哪里用？

GitHub README、语雀、飞书文档、博客等支持 Markdown 的地方都可以直接粘贴。

会保留对齐吗？

可以选择左对齐/居中对齐/右对齐，对应 Markdown 的冒号语法。
