SVG 波浪怎么用？

设置宽度、层高、振幅、波纹数、图层数并选择两个颜色，生成器输出带渐变的 SVG 代码，粘贴到网页中即可作为分区背景，贴满任意宽度。

为什么分层？

多层波浪叠加不同透明度可营造更大的纵深与流动感，是插画与后台登录页常见的装饰手法。

常见问题

生成的 SVG 会固定宽度吗？

不会，viewBox 高度固定而宽度随容器自适应，设为 preserveAspectRatio=none 后可在任意屏宽下满幅铺开。

可以改颜色吗？

可以，两个取色器决定渐变两端颜色，渐变方向默认水平；图层越多颜色过渡层次越丰富。

能保存或商用吗？

SVG 代码由你本地生成，可自由保存与用于商业页面；不建议另存图片，矢量代码体积更小更清晰。
