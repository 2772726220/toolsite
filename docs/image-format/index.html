为什么要转换图片格式？

不同平台对图片格式要求不同：网页推荐 WebP/AVIF，打印需求用 PNG/JPG。转换格式可大幅减小体积或兼容更多场景。

转换会损失画质吗？

工具支持质量滑块调节，有损格式（JPG/WebP/AVIF）可控制压缩质量，无损格式（PNG）保持原质量。
