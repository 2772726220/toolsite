为什么要估算文字宽度？

设计按钮、标签、标题或导出图片时需要预判文字会不会换行/溢出，估算宽度便于提前调整字号与容器。

估算准吗？

基于常见字体的平均字符宽度模型，误差一般在 ±10% 内；英文字母按实际宽度、中文按字号宽度估算。

常见问题

中文和英文算得一样吗？

不一样，中文每个字约占 1 个字号宽度，英文按字母平均宽度（约 0.5-0.6 字号）估算。

能选字体吗？

可以，内置常用字体族的平均宽度系数，也可手动填系数。

结果单位是什么？

像素（px），按你输入的字号计算。

需要联网吗？

不需要，本地估算，结果供参考。
