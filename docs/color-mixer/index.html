颜色混合怎么算？

按 RGB 通道线性加权：结果 = 颜色1 × 比例 + 颜色2 × (1 - 比例)，是最直观的调色模型。

混合结果用于什么？

可用于配色方案过渡、品牌色渐变推导、界面 hover 配色等设计场景。

常见问题

混合比例是百分比吗？

是，滑块 0-100% 表示颜色 1 的占比，另一端是颜色 2 的占比。

支持 HSL 吗？

当前按 RGB 线性混合（直观），输入支持 hex 与 rgb() 格式。

结果可以复制吗？

可以，结果区显示 HEX 与 RGB 两种格式，一键复制。

需要联网吗？

不需要，颜色计算在本地完成。
