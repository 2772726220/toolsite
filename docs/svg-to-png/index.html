为什么需要转 PNG？

PNG 兼容性最好，适合网页、邮件、聊天内直接展示；需要固定尺寸或想给 SVG 加上背景色时也通常先转成位图。

支持哪些 SVG 特性？

支持 width/height/viewBox 三种尺寸来源自动识别；缩放倍数最高 4 倍用于高清输出；背景色可自定义（含透明背景选择）。

常见问题

PNG 质量会下降吗？

PNG 是无损格式，视觉效果与 SVG 一致；建议先设 2 倍缩放再在高 DPI 屏幕检查清晰度即可。

支持透明背景吗？

支持。将背景色切换为透明后导出，PNG 会保留 alpha 通道。

图片会上传服务器吗？

不会。渲染完全在浏览器本地完成（SVG → Canvas → PNG），隐私安全。
