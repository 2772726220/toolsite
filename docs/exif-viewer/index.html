EXIF 信息查看器

读取 JPEG 照片的 EXIF 元数据：相机型号、镜头光圈、快门、ISO、拍摄时间与 GPS 坐标。图片全程在本地解析。

广告位（AdSense / 优量汇横幅）

EXIF 里能读到什么？

拍摄参数（光圈/快门/ISO/焦距）、相机型号、拍摄时间、图片尺寸，部分手机会写入 GPS 坐标方便回忆打卡地点。

为什么有的照片读不到？

部分编辑工具或平台会剥离 EXIF；微信聊天传输的照片多数已删除原图元数据。

常见问题

支持 PNG/WebP 吗？

目前支持 JPEG/Exif（APP1 段）最完整；PNG/WebP 的元数据结构不同，暂不支持。

会泄露隐私吗？

工具本地解析，不上传服务器；但请知悉原图本身包含这些信息，分享大图前可用图片编辑软件清除 EXIF。
