图片转 PDF 有什么用途？

把多张扫描件、截图、设计稿合并成一个 PDF 便于存档、打印和分享，是工作中最常见的文档整理需求。

转换在本地完成有什么好处？

图片不需要上传到服务器，隐私完全可控，速度也更快；工具内置高质量 JPEG 压缩，生成的 PDF 体积小且清晰。

常见问题

支持哪些图片格式？

支持浏览器可显示的常见格式：JPG、PNG、WebP、GIF 等，多选后点击生成即可合并。

图片会不会被压缩变形？

会等比缩放，不会拉伸变形。可选择最大边长（1600/1200/800px）与 JPEG 质量档位，兼顾清晰度与文件大小。

PDF 里每张图片是独立一页吗？

是的，每张图片生成独立一页，页面尺寸与图片像素一致，方便打印与排列。

我的图片会被上传吗？

不会，整个转换过程在浏览器本地完成，图片和生成的 PDF 都不会离开你的设备。
