词云是怎么生成的？

工具对文本分词并统计出现频次，中文按连续汉字切二字词、英文按单词统计，自动过滤常用停用词，频次越高字体越大、越靠近词云中心。

词云有什么用途？

把一篇文档、一份问卷或一段访谈浓缩成视觉标签，快速看出高频关键词，适合内容分析、汇报展示和社交媒体素材制作。

常见问题

中文分词准确吗？

采用二字词统计并过滤停用词，适合快速浏览关键词分布；如需精确分词建议使用专业 NLP 平台，本工具定位是轻量快速的词频可视化。

可以控制显示多少词吗？

可以，最大词数提供 40/60/100 三档；图形下方同时展示 TOP 20 高频词列表及占比。

词云图能保存吗？

可以针对画布直接截图保存，或另存为图片；文件均在浏览器本地生成，不下传任何数据。

支持哪些文本类型？

中英文混合文本均可，英文单词数≥2 会统计，中文优先识别二字词，无需预处理。
