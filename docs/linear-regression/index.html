什么是线性回归？

线性回归用一条直线 y=ax+b 描述两个变量的线性关系，最小二乘法让所有点到直线距离的平方和最小。

R² 怎么解读？

R² 越接近 1 说明拟合越好：0.9 以上线性关系很强，0.3 以下几乎无线性关系。

常见问题

数据格式是什么？

每行一对 x,y，用逗号或 Tab 分隔，如：1,2。

可以预测未来吗？

可以，输入 x 值即可用拟合直线预测 y，但仅在线性趋势延续时可靠。
