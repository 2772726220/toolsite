px 和 rem 有什么区别？

px 是固定像素，rem 相对根元素字号（默认 16px）。rem 更适合响应式布局，跟随根字号整体缩放。

怎么换算？

输入 px 值自动换算 rem（除以根字号），也可输入 rem 反算 px，支持批量。

常见问题

默认根字号是多少？

默认 16px，可自定义。

支持批量换算吗？

支持，多行输入自动批量换算。

反向换算可以吗？

可以，一键切换 px↔rem 方向。
