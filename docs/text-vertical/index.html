把文字转成竖排样式：每字换行（仿传统直排）或字间加全角空格。适合海报、条幅、古风排版。

两种模式有什么区别？

「逐字换行」让每个字占一行，最接近传统直排阅读习惯；「加全角空格」保持整句在同一段内竖排，适合排版节奏更密的场景。

支持表情与生僻字吗？

支持。转换按 Unicode 码点处理，Emoji 与组合字符不会被拆坏。

常见问题

结果怎么用？

点「复制结果」，再粘贴到文档或设计软件；逐字换行模式在宽底排布下即呈竖列效果。

能保留原有换行吗？

原文本中的换行会保留，适合先分好行再转换。

适合中文吗？

适合。中文逐字竖排最自然，英文缩写建议用加空格模式。
