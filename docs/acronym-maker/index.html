什么是首字母缩写？

取短语中每个单词的首字母组合成缩写，例如 Hyper Text Transfer Protocol → HTTP。工具会把单词里的非字母数字字符剔除后再取首字母。

支持哪几种缩写样式？

三种：首字母（HTTP）、首尾字母（每个词取头尾两个字母，如 Hyper → HR）、首字母加点（以 H.T.T.P. 形式，每个缩写字母后带一个点）。

适合什么场景？

给项目、产品、团队名称快速起缩写，或把冗长的英文职位、机构名压缩成易记的简称，英文和中英文混排短语都能处理。

常见问题

缩写结果为什么全部大写？

首字母缩写惯例使用大写，工具统一转成大写字母便于识别。

支持中文输入吗？

支持中英文混合输入；中文按「词」计入词数统计，但生成英文缩写时中文不产生字母，建议主要输入英文短语。

词和词之间怎么分隔？

按空白分隔单词，单词内部的标点与符号（如连字符、撇号）会被剔除后再取首字母。
