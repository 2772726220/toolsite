CSS 贝塞尔曲线怎么用？

cubic-bezier(x1, y1, x2, y2) 是 CSS transition 的缓动函数，四个参数控制曲线形状；本工具可拖点可视化调整并直接复制使用。

预设曲线分别长什么样？

ease、ease-in（加速）、ease-out（减速）、ease-in-out（先慢后快再慢）对应 CSS 规范的标准值；linear 为匀速直线。

常见问题

x 坐标为什么只能是 0-1？

CSS 要求两个控制点的 x 必须在 0-1 之间，否则时间函数无定义；y 可以超出产生回弹效果。

怎么做出回弹动画？

把 y 控制点设为大于 1 或小于 0，曲线会越过目标再回弹，形成弹跳感，例如 (0, -0.5, 1, 1.5)。

复制的是哪种格式？

复制后为 transition-timing-function: cubic-bezier(...) 整行，可直接粘贴到样式里；曲线上方实时预览动画效果。
