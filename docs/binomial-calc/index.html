二项分布什么时候用？

当试验独立、每次只有成功/失败两种结果、重复 n 次（如抽检、抛硬币、营销转化），随机变量=成功次数时使用 B(n,p)。

什么参数合理？

n 为试验次数（1-9999 整数），p 为单次成功概率（0-1）。结果同时给出点概率、左侧累计、右侧累计与均值 np、方差 np(1-p)。

常见问题

为什么结果可能与教科书有细微差别？

为在大 n 下保持数值稳定采用对数空间计算后还原，浮点误差通常在 1e-12 量级，可忽略。

泊松分布参数怎么选？

当 n 很大、p 很小（稀有事件）时可用泊松分布近似二项分布，λ=n·p，输入 λ 与发生次数 k 即可。

k 可以大于 n 吗？

不可以，二项分布要求 0≤k≤n；超过会在界面给出提示。
