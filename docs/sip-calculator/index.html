定投收益怎么算？

按复利按月计算：每月投入一笔，按年化收益率折算月收益率复利累积，期末总额减去总投入即为收益。

年化收益怎么预估？

历史数据仅供参考，建议按保守（3-5%）、中性（8%）与乐观（12%）多档试算，结果仅作规划参考。

常见问题

结果一定准确吗？

为理论复利估算，实际受市场波动、手续费影响，结果仅供规划参考，不构成投资建议。

支持按周定投吗？

支持，可切换定投周期，自动按对应频率计算。

复利是怎么复的？

每月定投金额按当前总资产 ×（1 + 月收益率）累积，即利滚利效应。

需要联网吗？

不需要，计算在本地完成。
