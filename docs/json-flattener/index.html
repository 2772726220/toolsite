JSON 扁平化是什么？

把嵌套的 JSON 对象转换成单层点分键对象，例如 {a:{b:1,c:{d:2}}} 会变成 {a.b:1,a.c.d:2}，数组元素用下标表示（如 e.0、e.1）。

什么时候需要扁平化？

对比两个 JSON 的差异、把嵌套数据存入键值对存储，或做日志与展示时，点分键形式更易读、更利于逐项比较。

可以还原吗？

可以。把点分键对象粘贴到「还原」模式，工具会重建嵌套结构，纯数字键自动识别为数组索引，实现扁平化与还原的往返转换。

常见问题

键名本身可以含点吗？

扁平化后以点作为层级分隔符；若原始键名含点，还原时可能产生歧义，建议避免在键名中使用点。

空对象和空数组怎么处理？

顶层空对象/空数组用键 value 表示；嵌套的空对象与空数组会保留为 {} 和 []。

数据会上传吗？

不会，转换全部在浏览器本地完成。
