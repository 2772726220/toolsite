JSON 转 JSON Schema

粘贴任意 JSON，自动推断出对应的 JSON Schema（draft-07），可一键复制，方便接口文档、表单校验与前后端联调。

广告位（AdSense / 优量汇横幅）

JSON Schema 有什么用？

JSON Schema 是用 JSON 描述数据结构的标准（draft-07），前端表单校验、接口文档生成、mock 服务都可直接引用，避免手写类型定义出错。

生成的 Schema 是否规范？

遵循 JSON Schema draft-07，对象生成 properties + required，数组取首元素推断 items，数字自动区分 integer/number。

常见问题

数组怎么推断 items？

按数组第一个元素推断类型；空数组 items 为 {}，需要时自行补充。

能生成 required 吗？

默认生成对象 required 字段，可在界面取消勾选。

我的数据会上传吗？

不会，全部在浏览器本地解析生成。
