#向量#点积#叉积

什么是点积和叉积？

点积 a·b = Σ(aᵢ·bᵢ)，结果是一个数，衡量两向量同向程度；叉积 a×b 只在三维向量上定义，结果仍是向量，方向遵循右手定则，模长等于两向量张成的平行四边形面积。

怎么求向量夹角？

由公式 cosθ = a·b / (|a|·|b|) 反解夹角。cosθ = 1 时两向量同向、夹角 0°，cosθ = 0 时垂直、夹角 90°。零向量与任何向量的夹角未定义，工具会显示占位符。

支持多少维向量？

两个向量只要维数相同即可运算（二维、三维乃至任意维），加减与点积对任意维通用，只有叉积需要三维向量，其余场景不会误用。

常见问题

向量怎么输入？

用英文逗号分隔数字即可，例如「1, 2, 3」。两个向量的维数必须相同，否则会提示错误。

夹角结果显示为多少位？

夹角以度为单位保留两位小数输出，并同时给出 A+B、A-B、点积、模长等完整结果。
