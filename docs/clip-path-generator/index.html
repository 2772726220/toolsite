clip-path 能做什么？

matrix 无需切图即可给元素做任意形状裁剪：多边形头像、圆形卡片、渐变背景镂空、产品图去直角等，是纯 CSS 的视觉效果利器。

inset 的圆角怎么写？

inset(top right bottom left round 半径)，例如 inset(10% 20% round 16px)，半径支持 px、%、em 等任意长度单位。

常见问题

坐标用什么单位？

默认用百分比相对元素尺寸定位，任意宽高都自适应；也支持直接填写像素数值。

生成的代码怎么用？

复制剪贴板里的 clip-path: …; 一行即可，粘贴到任意元素的 style 或 class 中；如需旧浏览器兼容请在把 -webkit-clip-path 一并加上。

支持实时预览吗？

支持。调整点坐标、颜色、尺寸后预览框立即更新，点同样位置即可复制。
