什么是双色调？

Duotone 把原图每个像素按亮度在两色之间渐变映射：暗部倾向第一色，亮部倾向第二色，形成简洁又有冲击力的视觉风格。

适合什么场景？

常用于品牌视觉、社交媒体封面、电子音乐海报等，能快速统一多张照片的色调。

常见问题

支持什么图片格式？

支持浏览器可解码的常见格式（JPG、PNG、WebP 等），处理后导出 PNG。

图片会上传吗？

不会。处理完全在浏览器本地完成，图片不会离开您的设备。

强度滑块是什么？

强度 100% 为纯双色调；调低会向原图颜色靠近，适合做轻度风格化。
