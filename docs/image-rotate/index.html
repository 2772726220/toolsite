图片方向不对怎么办？

手机竖拍的照片在部分平台显示横了，用旋转工具一键纠正方向。支持 90 度、180 度、270 度旋转和水平/垂直翻转。

旋转会损失画质吗？

旋转 90/180/270 度不会损失画质；任意角度旋转需要重采样，可能有轻微损失。
