如何提取图片主色？

上传图片后自动分析并生成 5/10/20 色主色调色板，每个颜色附带 HEX/RGB/HSL。

能取任意像素颜色吗？

支持吸管模式，鼠标悬停显示放大镜，点击即可提取该像素颜色。

支持导出吗？

支持复制单个色值，也支持导出 CSS 变量与 Tailwind 配置色板。

支持 PNG、JPG、WebP、GIF 等浏览器可读的常见格式。

配色方案会保存吗？

本地保存最近使用的调色板，关闭后恢复。
