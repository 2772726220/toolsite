正则转义工具

把包含 .* + ? ( ) [ ] { } ^ $ \ | 等元字符的普通文本转义成可安全用于正则表达式的字面量。

广告位（AdSense / 优量汇横幅）

为什么要转义正则元字符？

在正则里 . * ? 等字符有特殊含义，直接匹配会意外吞掉内容或报错。转义后它们只当普通字符匹配，适合检索文件名、括号文本等场景。

转义后的结果怎么用？

可直接用于 new RegExp('...') 或正则字面量 /.../，也可嵌入字符串模板。

常见问题

斜杠 / 会转义吗？

不会。JS 正则里 / 只在字面量分隔符场景有特殊位置含义，代码里用 new RegExp 时无需转义。

支持转义为 JSON 字符串吗？

需要把反斜杠再转义一层时（如放进 JSON），请自行把结果里的 \ 替换为 \\。
