为什么要统计字数？

公众号投稿、论文、新媒体写作都有字数要求，交稿前统计字数避免超限或不足。实时统计让写作过程心里有数。

字数和中文字数有什么区别？

字数包含所有语言文字；中文字数只统计汉字。英文按单词统计，工具提供完整的多维度统计指标。

常见问题

统计哪些指标？

总字数、中文字数、英文字数、字符数（含空格/不含空格）、段落数、行数、阅读时间。

英文单词怎么算？

按空白分隔的连续字母序列算一个单词，与常见文档软件的算法一致。

粘贴大段文字会卡吗？

不会，统计在本地毫秒级完成，几十万字也能流畅统计。

统计结果准确吗？

准确。统计逻辑与主流写作软件一致，可作为交稿字数的参考依据。
