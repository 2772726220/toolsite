什么是正则表达式？

正则表达式是一套描述字符串匹配模式的语法，如验证手机号、提取邮箱、过滤脏数据都能用正则实现，是程序员的日常工具。

怎么用这个工具？

上方输入正则表达式，下方输入待匹配文本，匹配结果实时高亮显示，并列出所有匹配的具体内容，方便调试。

常见问题

我的内容会上传吗？

不会，正则匹配完全在浏览器本地执行。

匹配结果怎么查看？

文本中的命中部分会高亮，下方列表会逐一列出每个匹配的完整内容、起始位置和长度。

支持分组捕获吗？

支持，匹配列表会显示捕获组内容，方便提取部分信息。

正则写错了会怎样？

工具会提示语法错误位置，不影响继续编辑。
