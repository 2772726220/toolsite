农历和公历怎么换算？

农历是阴阳合历，按月相定月、闰月补齐，本工具基于 1900-2100 的历法数据表精确换算。

能查哪些信息？

农历日期、干支、生肖、节气、大小月与公历对应星期。

常见问题

支持范围多大？

覆盖 1900 年至 2100 年，范围内均可换算。

闰月怎么显示？

闰月会标记为「闰X月」，如闰四月。

可以反查吗？

支持输入农历日期反查对应公历日期与星期。
