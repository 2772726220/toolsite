怎么对比两个 JSON？

左右粘贴或上传两个 JSON，工具递归遍历键值，标记仅左侧有/仅右侧有/值不同/类型不同四种差异类型。

数组怎么对比？

支持按索引对比、按唯一键对比、智能对齐三种模式，适应有序/无序数组场景。

常见问题

支持大文件吗？

支持，虚拟滚动渲染，百 MB 级 JSON 也能流畅对比。

能忽略某些字段吗？

支持配置忽略键名正则（如 timestamp、id 等动态字段）。

能导出差异报告吗？

支持导出 JSON Patch (RFC 6902) 格式补丁文件。

支持 YAML 对比吗？

可先用 YAML/JSON 互转工具转为 JSON 再对比。
