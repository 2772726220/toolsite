怎么测键盘？

在文本框或页面任意位置按下任意按键，对应按键会高亮显示，松开后恢复，若某键无反应即为失灵。

能测组合键吗？

支持 Shift/Ctrl/Alt 等修饰键，按住时会高亮并显示组合结果。

常见问题

测试结果准吗？

浏览器会报告操作系统收到的按键事件，可用于排查物理键盘与驱动问题。

按了没反应怎么办？

先确认输入法是否抢占按键，再检查该键是否为组合键或 Fn 层切换。
