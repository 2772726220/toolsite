怎么算实际工作时长？

实际工时 = 下班时间 - 上班时间 - 午休时长。例如 9:00-18:00 午休 1 小时，实际工作 8 小时。

跨天怎么算？

如夜班 22:00-次日 6:00，工具自动处理跨零点情况，结果仍为扣除午休后的实际时长。

常见问题

支持跨天吗？

支持，自动识别下班时间早于上班时间的情况并按跨天计算。

午休可以不扣吗？

可以，午休时长填 0 即可。

结果单位是什么？

显示为「X 小时 Y 分钟」，同时给出小数小时便于填报工时。

需要联网吗？

不需要，纯本地计算。
