色轮配色原理？

基于色相环几何关系：互补色相差 180°，三角色 120°，类似色相邻 30°，分裂互补取互补色两侧各 30°，保证视觉和谐。

怎么用生成的配色？

复制 HEX/RGB/HSL 值到设计软件或 CSS，支持一键导出 Tailwind config、SCSS 变量、JSON 供代码直接引用。

常见问题

支持色盲安全检查吗？

内置 WCAG 对比度检测，标注不达标组合。

可以锁定某个颜色吗？

支持锁定主色，其余色随规则自动计算。

支持导出图片色板吗？

支持导出 PNG 色板图，含色值标注。

支持 P3 广色域吗？

当前版本基于 sRGB，P3 支持规划中。
