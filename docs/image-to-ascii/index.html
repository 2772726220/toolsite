什么是字符画？

字符画用不同字符的疏密来模拟灰度，把图片像素的明暗映射到字符上，形成用文本构成的艺术图像，常用于代码注释、终端艺术与博客装饰。

怎么控制清晰度？

字符密度越高、图片缩小比例越大越清晰；也可以勾选反色获得不同风格。
