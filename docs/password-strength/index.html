为什么要检测密码强度？

弱密码是账号被盗的最大原因，检测工具帮你评估密码是否安全并给出改进方向。

如何提高密码强度？

使用 12 位以上、包含大小写字母数字符号、避免生日和常见单词，不同网站用不同密码。

常见问题

检测数据会泄露吗？

不会，所有检测都在本地浏览器完成，不联网。

什么算强密码？

长度 12 位以上且包含多种字符类型、不重复不常见。

支持中文密码吗？

支持，长度越长越安全。

会被记录吗？

完全本地运行，不保存任何输入。
