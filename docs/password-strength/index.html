为什么要检测密码强度？

弱密码是账号被盗的最大原因，检测工具帮你评估密码是否安全并给出改进方向。

如何提高密码强度？

使用 12 位以上、包含大小写字母数字符号、避免生日和常见单词，不同网站用不同密码。
