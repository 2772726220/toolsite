混合模式是什么？

混合模式定义两层像素如何合并：正片叠底让亮色更透、暗色保留；滤色反之；叠加/柔光用于增加层次；差值与柔光适合做艺术效果。

透明度和模式怎么搭配？

先选模式再调前景透明度：透明度 100% 完全叠加，调低则逐渐透出底图。
