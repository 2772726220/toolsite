什么是分形噪声？

分形噪声由多个不同频率的噪声层（Octave）叠加而成：低频层决定大范围起伏，高频层补充细节，让结果更自然连续。工具默认叠加 3 层 Octave 生成 256×256 灰度纹理。

怎么保证纹理可复现？

纹理由确定性哈希与线性同余随机数生成，同一个随机种子会得到完全相同的图案，方便复现、对比或再次使用。

能用来做什么？

灰度噪声纹理常用作游戏地形高度图、程序化贴图、艺术背景与设计灵感，输出为纯灰度图，可直接作为贴图素材或高度数据。

常见问题

随机种子怎么用？

在输入框填数字作为种子，留空或非法时会自动用当前时间生成；同一个种子永远产生同一张纹理。

可以调整大小或图层数吗？

当前固定生成 256×256、3 层 Octave 的灰度纹理，核心算法函数便于自行扩展与实验。

生成的图能保存吗？

在支持画布的环境中会绘制到页面 canvas，可直接右键保存图片。
