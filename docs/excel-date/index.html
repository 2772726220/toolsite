Excel 日期序列号转换

Excel 把日期存成从 1900 年开始的天数（整数序列号），本工具在日期和序列号之间一键互转，全程本地计算。

Excel 日期序列号是什么？

Excel 用从 1900-01-00 开始的连续天数保存日期，序列号 1 表示 1900-01-01，45292 表示 2024-01-01。理解序列号有助于排查 VLOOKUP 与日期比较的坑。

这个工具和普通日期换算有什么不同？

本工具严格按 Excel 的 1900 日期系统计算，并处理了著名的 1900-02-29 假日期 bug，保证 1900-03-01 之后的序列号与办公软件完全一致。

常见问题

序列号 60 是什么？

Excel 的 bug 把 1900 年当成闰年，序列号 60 对应不存在的 1900-02-29。本工具会明确提示，1899 年之后的日期转换不受影响。

支持到多远的日期？

支持 1900-01-01 到 9999-12-31，对应序列号 1 到 2958465。
