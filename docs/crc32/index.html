广告位（AdSense / 优量汇横幅）

CRC32 是什么？

一种 32 位循环冗余校验算法，用于检测数据在传输或存储中的意外损坏。

能算文件和文本吗？

都支持，粘贴文本或上传文件即可得到 8 位十六进制校验和。

常见问题

结果格式是什么？

8 位十六进制数，如 123456789 的 CRC32 为 CBF43926。

支持大文件吗？

支持，浏览器本地读取计算。

数据会上传吗？

不会，本地计算。

与 MD5 有区别吗？

CRC32 更快但碰撞率更高，适用于完整性校验而非安全加密。
