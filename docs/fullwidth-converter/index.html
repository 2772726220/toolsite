为什么要做全角半角转换？

从 PDF/微信复制的英文和数字常变成全角（ｈｅｌｌｏ、１２３），代码报错或排版错位。转成半角即可正常使用。

转换会误伤中文吗？

不会。汉字本身不受影响，只处理全角字母数字、全角空格和常见中文标点。
