MIME 类型是什么？

服务器与浏览器约定文件内容类型的标准标识，即响应头 Content-Type 里的取值，由主类型/子类型组成，如 text/html。

为什么需要查 MIME？

配置服务器、写上传接口、设置响应头或处理文件下载时，正确的 MIME 能避免浏览器乱码或误触发下载。
