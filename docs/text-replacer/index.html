多组规则会按顺序执行吗？

会。多组规则从上到下依次应用，后一组在前一组的结果上继续替换，适合制作脱敏、格式化等组合处理。

正则替换怎么用？

选择「正则表达式」模式后，查找框填写正则（如 \\d+ 匹配数字），替换内容支持普通文本。正则非法时会提示错误。

常见问题

「全部替换」和默认的区别？

勾选全部替换会替换符号的所有出现位置；取消后只替换第一处。

替换内容是纯文本吗？

正则模式下替换内容按普通文本处理，不做特殊展开，避免意外行为。

能处理大段文本吗？

可以。处理在浏览器本地完成，常见大小的文本即时出结果。
