为什么要把图片转成 Base64？

Base64 Data URI 可以把小图片直接内联进 CSS 或 HTML，减少 HTTP 请求，适合图标、背景等小图；但体积约增加 33%，大图不建议。

转换会压缩图片吗？

不会，Base64 编码只是图片字节的另一种表示，不改变图片内容与质量。

常见问题

转换会失真吗？

Base64 是无损编码，图片内容完全不变，仅在传输/内联时体积增加约 1/3。

会泄露隐私吗？

不会，图片在本地浏览器处理，不上传任何服务器。

支持哪些格式？

JPG、PNG、WebP、GIF、SVG 等浏览器可读取的图片格式均支持。

生成的数据能用在哪里？

可用于 CSS background-image、HTML img src、图片 API 接口调试、邮件内嵌图片等场景。
