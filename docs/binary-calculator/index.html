二进制怎么计算？

二进制是计算机底层表示方式，逢二进一。本工具把输入按二进制解析并计算，结果同时显示二进制与十进制，方便对照。

位运算有什么用？

位运算常用于底层优化、权限标志、颜色处理等场景，例如 & 取交集、| 取并集、^ 翻转。

常见问题

支持负数吗？

支持，输入可用补码表示负数（如 -1 = 全 1），结果按选中位宽解释。

位宽不同结果会不同吗？

会，特别是溢出与符号位处理，建议按实际场景选择 8/16/32 位。

能算小数吗？

本工具按整数运算，支持十进制输入自动转二进制。
