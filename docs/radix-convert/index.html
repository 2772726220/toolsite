#进制#转换
广告位（AdSense / 优量汇横幅）

进制转换有什么用？

编程中地址、颜色、编码常用十六进制，位运算用二进制，进制转换是程序员高频需求。

支持哪些进制？

支持二进制、八进制、十进制、十六进制，输入任意一种自动换算其余三种。

常见问题

支持负数和小数吗？

支持整数（含大数，自动按高精度计算）；小数暂不支持。

十六进制字母怎么输入？

支持 A-F 大写或小写。

数据会上传吗？

不会，本地计算。

支持大数吗？

支持，超出常规范围的超大数也能正确换算。
