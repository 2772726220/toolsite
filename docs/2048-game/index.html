2048 怎么玩？

用方向键移动方块，相同数字碰撞会合并翻倍并累计分数，目标是拼出 2048。每次移动会随机生成一个新方块（90% 概率为 2）。

2048 有通关技巧吗？

把最大的数字固定在角落，如左下角；优先朝一个方向构建长列，避免最大方块被夹在中间；一旦方块全部填满且无法合并就游戏结束。

常见问题

计分规则是什么？

每次合并会累加合并后的数字，比如两个 128 合并时加 256 分；最高分保存在浏览器本地。

支持触屏手机玩吗？

支持，页面提供上/下/左/右键按钮可以点击操作，桌面端直接按键盘方向键更爽快。

最高分会丢失吗？

最高分保存在浏览器 localStorage，正常情况长期保留；清除浏览器数据会丢失。

游戏数据会上传吗？

不会，游戏完全在浏览器本地运行，无任何网络请求。
