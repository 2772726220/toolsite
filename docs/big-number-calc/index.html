为什么普通计算器会溢出？

普通计算器用 64 位浮点存储数字，超过 2^53 便开始丢失精度（如 16 位以上数字）。本工具使用 BigInt 任意精度整数，几位都可以精确运算。

适合什么场景？

阶乘、大数组合、加密相关的取模运算、竞赛题与教学演示等需要精确整数的场合。

常见问题

支持负数吗？

支持。A、B 均可带正负号，取模按数学约定返回非负结果。

阶乘能算到多大？

界面提供 5!/20!/100!/500! 快捷按钮，也接受任意 ≤100000 的输入（更大请谨慎运算时间）。

乘方有限制吗？

指数需为非负整数且不超过 100000，防止结果无限膨胀导致浏览器卡顿。
