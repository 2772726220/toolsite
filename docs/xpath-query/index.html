支持哪些 XPath 语法？

核心子集：绝对/相对路径、后代 //、属性 @、text() 文本节点、位置谓词 [n] 与 [last()]、属性等值/不等谓词。

XPath 有什么用？

不写代码从 XML/HTML 结构中精准提取节点，工具开发、接口调试、数据清洗场景常用。

常见问题

能处理不规范的 XML 吗？

工具内置轻量解析器，标签必须配对闭合；未闭合会提示错误与大致位置。

大小写敏感吗？

标签与属性匹配默认大小写敏感，与标准 XPath 一致。

数据会上传吗？

不会。解析与查询全部在浏览器本地完成。
