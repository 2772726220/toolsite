#方程#求根
广告位（AdSense / 优量汇横幅）

怎么判断根的情况？

看判别式 Δ=b²-4ac：Δ>0 两个不等实根，Δ=0 一个重根，Δ<0 两个共轭复根。

求根公式是什么？

x = (-b ± √Δ) / (2a)。

常见问题

a 可以为 0 吗？

a=0 退化为一次方程，也能求解。

显示求解过程吗？

显示判别式、求根公式代入和最终根。

支持复数根吗？

支持，Δ<0 时显示复数根形式。

结果精确吗？
