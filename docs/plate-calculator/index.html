怎么算每侧要放多少片？

每侧需要 = (目标总重 - 空杆重) ÷ 2，再从大中小号杠铃片里凑出这个数。例如 20kg 空杆配 100kg 总重，每侧 40kg，一片 25kg 加一片 15kg 即可。

内置哪些杠铃片规格？

标准通用规格：25、20、15、10、5、2.5、1.25、0.5kg，按从大到小贪心凑片，并给出大号片在内侧、小号片在外的装法。

凑不齐会怎样？

目标重量若无法用标准片精确凑出（如每侧需要 0.75kg），工具会明确提示每侧还差多少，方便换成更合适的重量。

常见问题

结果单位可以切换吗？

结果显示单位可在 kg 与 lb 间切换，但内置片规格为固定数值（25/20/15/10/5/2.5/1.25/0.5），按你选择的标签显示。

空杆重量指的是什么？

奥林匹克标准杆通常 20kg，女子杆约 15kg，请按实际空杆填写；目标总重必须大于等于空杆重量。

输出顺序怎么看？

先放大片在内侧、小片靠外；相同规格会合并写成 N×规格，例如 2×25kg。
