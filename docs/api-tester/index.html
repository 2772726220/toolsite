能替代 Postman 吗？

覆盖核心调试功能：请求构建、环境变量、历史记录、cURL 互转。云端同步/团队协作等高级功能暂不支持。

支持自动化测试吗？

支持简单断言(状态码/响应时间/JSON 路径)，批量运行规划中。

常见问题

请求会经过代理吗？

直接从浏览器发起，受同源策略限制；跨域需目标服务器配置 CORS 或自行部署代理。

支持 GraphQL 吗？

支持，Body 选择 GraphQL，输入 query/variables。

数据会保存吗？

历史记录/收藏/环境变量存本地 IndexedDB，不上传服务器。

能导出 Postman Collection 吗？

支持导出 Postman Collection v2.1 格式 JSON。
