什么是子网掩码？

子网掩码用于区分 IP 地址中的网络部分和主机部分。例如 255.255.255.0 表示前 24 位为网络位，后 8 位为主机位，即 /24 子网。

网络地址和广播地址怎么算？

网络地址是主机位全 0，广播地址是主机位全 1。两者都不能分配给主机使用，实际可用主机数 = 2^n - 2（n 为主机位数）。

常见问题

/24 子网有多少个可用 IP？

/24 有 256 个地址，减去网络地址和广播地址，可用主机数为 254 个。

可以输入掩码长度吗？

可以，直接输入掩码长度如 24、26、30，会自动换算成点分十进制掩码。

什么是 CIDR？

CIDR（无类别域间路由）用 /长度 表示子网，如 192.168.1.0/24，是子网划分的标准写法。

结果可靠吗？

计算基于标准位运算，网络地址、广播地址、可用范围均精确无误。
