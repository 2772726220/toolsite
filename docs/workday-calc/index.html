工作日怎么算？

默认去除周六周日，按周一到周五计为工作日。

有什么用？

算考勤、算交付周期、排项目计划，或算 N 个工作日后是哪天。

常见问题

包含法定节假日吗？

基础版只排除周末，法定节假日需按国家安排另行调整。

支持反算吗？

支持，计算从某天起 N 个工作日后是哪一天。

数据会上传吗？

不会，本地计算。

首尾日期算吗？

包含首尾日期，开始日期是工作日则计入。
