还款额低于月利息会怎样？

每月还款连当月利息都不足以覆盖时永远还不清余额，工具会给出提示并建议提高月供。

如何尽快还清？

提高每月还款额是最快路径；利率越高，多还的部分对冲利息的效果越明显。

常见问题

计算结果准确吗？

采用标准等额还本法（先还利息后还本金）逐月滚动计算，上限 1200 个月（100 年）。

包含手续费吗？

不含手续费，仅按年利率 APR 折算月利率计算纯利息。
