什么是等额年金？

等额年金（等额本息）指在固定期数内每期支付相同金额的付款方式，计算公式为：每期付款 = 现值 × r × (1+r)^n / ((1+r)^n - 1)，其中 r 为每期利率、n 为期数。

和房贷月供有什么关系？

房贷的等额本息还款就是典型的等额年金：贷款额是现值、月供是每期付款。例如贷款 10000、每期利率 5%、分 10 期，每期约还 1295.05，总利息约 2950.46。

工具会返回哪些结果？

一次给出每期应还金额、总还款额与总利息。利率按「阶段利率」理解，即每期利率，与期数口径匹配，符合按揭计算习惯。

常见问题

输入的利率是年利率吗？

页面标为「阶段利率」，即每一期的利率：若按月供请填月利率，按年供则填年利率。本工具不会对阶段利率再做期数拆分。

利率为 0 时会怎样？

利率为 0 时每期付款等于现值除以期数，纯本金均摊、总利息为 0，工具已做专门处理避免除零。
