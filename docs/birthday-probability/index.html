生日悖论概率计算器

计算 n 个人里至少有两人同一天生日的概率，理解为什么 23 人的班级就有约一半概率「撞生日」。

广告位（AdSense / 优量汇横幅）

什么是生日悖论？

只需要 23 人，就有一半概率「至少两人同一天生日」。因为比较的是任意两人之间的组合数 C(n,2)，而不是和固定某天撞。

怎么算的？

概率 = 1 − 所有人生日互不同，乘积式在对数空间内计算避免溢出，人数超过天数概率为 1。

常见问题

算法准确吗？

采用精确的对数空间乘积，误差在浮点精度内；默认 365 天，闰年可自填 366。

人数能填多大？

最多 1,000,000 人，对数十万人的哈希碰撞分析同样适用（换成 365 天之外的取值即可）。
