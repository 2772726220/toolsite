什么是 slug？

slug 是 URL 中可读的部分，例如 https://site.com/post/how-to-cook-rice 中的 how-to-cook-rice，对 SEO 友好。

中文标题怎么转 slug？

可以选择转拼音（ru-he-peng-ren-mi-fan）或保留中文（URL 编码），本工具默认转拼音便于阅读。

常见问题

支持哪些转换选项？

支持保留中文/转拼音、是否小写、自定义分隔符、去除停用词等选项。

转出来安全吗？

会去除所有非法字符，只保留字母、数字和分隔符，可用于 URL 与文件名。

有字数限制吗？

建议在 200 字以内，过长会截断到指定长度。
