SVG 为什么要优化？

设计工具导出的 SVG 常含大量冗余：编辑器元数据、过度精确的小数、未使用的定义、冗长的 ID。优化可减小 30-80% 体积。

优化会影响显示吗？

默认安全模式仅移除冗余，不改变视觉。可开启激进模式进一步压缩路径。

常见问题

支持 SVG 1.1 完整规范吗？

支持常用子集，复杂滤镜/动画/脚本可能需手动处理。

会破坏 CSS/JS 引用的 ID/类吗？

可配置保留特定 ID/类名模式，避免破坏外部引用。

支持批量优化吗？

支持多文件上传，统一参数批量处理，打包下载。

精度设置建议多少？

默认 3 位小数，通常够用；打印级可设 4-5 位。
