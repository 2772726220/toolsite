为什么用 SVG 做 favicon？

SVG 是矢量格式，任意分辨率都清晰，文件极小，现代浏览器都支持。也可以嵌入 HTML 的 data URI 中使用。

SVG favicon 兼容性如何？

Chrome、Firefox、Edge、Safari 等现代浏览器均支持 SVG favicon。老版本 IE 不支持，可同时提供 ICO 备用。
