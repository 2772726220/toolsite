为什么要把 JSON 转成 TS 类型？

后端接口返回的 JSON 结构直接生成 TS 类型，可保证前后端字段一致，避免手写类型出错，让 IDE 自动补全与类型检查生效。

生成的类型怎么用？

把生成的 interface 粘贴到 .d.ts 或 .ts 文件中即可，配合 axios 等请求库直接泛型化使用。

常见问题

支持嵌套对象吗？

支持，嵌套对象会自动生成独立 interface，数组会识别元素类型并标注为可重复字段。

空数组或空对象怎么办？

空数组默认生成 any[]，空对象生成 Record，可在生成前勾选忽略空值。

字段名大小写会变吗？

保持原始大小写，并处理带引号的非常规字段名（如含连字符的字段）。

会泄露数据吗？

不会，转换全部在浏览器本地完成，不发送任何数据。
