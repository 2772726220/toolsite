Flexbox 和 Grid 区别？
Flexbox 是一维布局(行或列)，适合组件级/导航/居中；Grid 是二维布局，适合页面级整体布局。两者常配合使用。
生成的代码兼容性？
现代浏览器全支持(IE10+ 需前缀)，生成代码含标准写法。

    
常见问题

    
支持嵌套 Flex 吗？
预览区支持容器嵌套，代码生成以单层为主，嵌套需手动组合。
支持 gap 属性吗？
支持，现代浏览器原生支持 gap/row-gap/column-gap。
能导出 Tailwind/UnoCSS 类名吗？
支持一键导出 Tailwind/UnoCSS 实用类名字符串。
子项 align-self 怎么用？
单独覆盖某子项的交叉轴对齐，适合导航栏 logo 居中、其余项拉伸等场景。
