压缩会改变代码行为吗？

不会。白名单式扫描器识别字符串/模板串/正则字面量并原样保留，换行会保留以避免 ASI（自动分号插入）改变语义。

与专业混淆器有差别吗？

本工具做空白压缩而非变量重命名，输出仍可读，适合粘贴压缩、代码提交前瘦身与存档。

常见问题

支持 ES6+ 吗？

支持。基于字面量扫描不限语法版本，模板字符串、字符类正则均原样保留。

会保留换行吗？

会。折行保留（同行内多处空白折叠为单空格），避免 return 后换行等 ASI 场景语义改变。

代码会上传到服务器吗？

不会。完全在本地处理，隐私安全。
