什么是字体栈？

font-family 属性后跟的一串备选字体列表（如 font-family: Segoe UI, Arial, sans-serif）就是字体栈：浏览器从前到后逐个尝试，前面的不可用就用后面的回退。

内置哪些平台预设？

Windows、macOS、iOS、Android、系统默认、无衬线体、衬线体、等宽体、中文字体九大类，每套都按平台生态排好顺序，例如 Windows 优先 Segoe UI，中文字体栈优先 PingFang SC 与微软雅黑。

回退顺序重要吗？

重要。把最优先的字体放最前、通用家族名（sans-serif、serif、monospace）放最后兜底，既能适配任意设备，又能尽量贴近设计预期。工具实时预览效果。

常见问题

等宽字体栈适合什么场景？

代码编辑器、终端界面与需要数字对齐的表格建议用等宽体，例如 SF Mono、Consolas、Menlo、monospace 的组合。

中文字体排序有什么讲究？

把目标平台最常见的字体放最前（如 PingFang SC、Microsoft YaHei、Source Han Sans），避免额外加载字体文件。

生成的代码怎么用？

把生成的 font-family 声明粘贴进 CSS 规则即可，也可以放到 :root 的 CSS 变量里统一管理。
