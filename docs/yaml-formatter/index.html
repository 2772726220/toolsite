为什么要 JSON 转 YAML？

YAML 用缩进表达层级，比 JSON 的括号更易阅读，常用于配置文件（如 docker-compose、GitHub Actions、Kubernetes）。把 JSON 粘贴进来即可一键生成缩进清晰的 YAML。

转换时特殊字符怎么处理？

工具自动为需要加引号的字符串做转义：包含冒号、井号、特殊符号、换行的字符串，以及与 true、false、null 等关键字冲突的字符串都会安全加引号，空字符串输出为两个单引号。

数组和嵌套对象怎么输出？

嵌套对象按空格缩进逐层展开；数组每项以「- 」开头，对象数组会继续缩进子键名，保证 JSON 与 YAML 结构一一对应、可还原。

常见问题

能转换多大的 JSON？

粘贴文本在浏览器本地解析，无固定大小上限，超大 JSON 建议分批处理避免卡顿。

输入的必须是 JSON 吗？

是。本工具是 JSON 转 YAML 方向，输入非法 JSON 会提示具体解析错误。

数据会上传吗？

不会，转换全部在浏览器本地完成。
