视口和屏幕分辨率有什么区别？

视口是浏览器里网页实际可用的区域，屏幕分辨率是显示器物理像素。移动端两者差异很大，响应式开发以视口为准。

设备像素比（DPR）是什么？

DPR=物理像素/逻辑像素。iPhone 等高清屏 DPR 为 2-3，同样是 375px 宽，物理像素数多得多。
