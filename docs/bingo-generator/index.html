宾果卡怎么玩？

宾果（BINGO）是喊号或翻词、圈出匹配格子的经典游戏。工具生成 n×n 网格，格子内容可自定义词汇（用空格或逗号分隔），适合课堂复习、破冰与聚会等多人场景。

中心免费格是什么？

奇数尺寸（3×3、5×5、7×7）网格的中心格为免费格 ★，直接视为已标记，降低开局难度；偶数尺寸没有免费格。

怎么判定获胜？

任意完整的一行、一列或一条对角线被全部标记即 BINGO。词汇不足时工具会自动循环补齐并加序号区分，保证每格都有内容。

常见问题

网格支持多大？

边长 3-7，即 3×3 到 7×7，默认 5×5。

词汇不够格子数量怎么办？

不足时会从已有词汇循环补充并添加序号后缀（如 苹果·1），保证每格都有内容。

课堂上能用吗？

适合词汇复习、听力练习等教学活动；词汇与随机种子都可自定义，同一种子生成完全相同的卡。
