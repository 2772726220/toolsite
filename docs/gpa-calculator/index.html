GPA 怎么算？

GPA = Σ(课程绩点×学分) ÷ Σ学分，绩点由百分制成绩或等级换算得到。

4.0 制和 5.0 制什么区别？

5.0 制给高绩点成绩更多上探空间，保研、出国看的是加权平均分与排名，GPA 口径需以学校为准。
