为什么对比度重要？

低对比度文字在弱光、色弱人群中难以辨认，WCAG 规定正文至少 4.5:1、大号字 3:1 才算达标。

怎么用？

选择或输入前景色和背景色，自动给出比值与达标等级，实时更新。

常见问题

达标标准是什么？

AA 级正文 ≥4.5:1、大号/粗体 ≥3:1；AAA 级正文 ≥7:1、大号 ≥4.5:1。

支持透明背景吗？

仅支持不透明色，透明会按白底近似计算。

能直接调颜色吗？

可以，点色块实时调整并即时更新结果。

需要联网吗？

不需要。
