贪吃蛇怎么玩？

鼠标点击画面或按方向键/WASD 控制蛇头方向，吃到红色食物蛇身变长、分数加一，撞到墙壁或自己的身体则游戏结束。

怎么加速？

速度有三档（慢/中/快），慢档 160ms 一格适合新手，快档 75ms 一格考验反应。

常见问题

可以连续按方向键吗？

可以，转向指令会排队逐格执行，但不能 180° 掉头，防止直接撞回自身。

食物会出现在蛇身上吗？

不会，食物只出现在空白格，蛇越长可用空间越小，填满棋盘会提示获胜。

怎么重新开始？

点击「重新开始」按钮即可，分数与蛇身都会重置，也可以在结束后直接点按钮开新局。
