什么是斐波那契数列？

斐波那契数列从 F0 = 0、F1 = 1 开始，之后每一项都等于前两项之和：F(n) = F(n-1) + F(n-2)，得到 0、1、1、2、3、5、8、13…… 自然界中很多螺旋生长符合这一规律。

相邻两项比值和黄金比例有什么关系？

当 n 足够大时，F(n)/F(n-1) 无限趋近于黄金比例 (1+√5)/2 ≈ 1.6180339887。工具在 n>0 时直接输出这一比值，可直观看到逼近过程。

第 n 项能算多大？

受 JavaScript 安全整数范围限制，工具支持 0-78 项，F78 = 8944394323791464 是能精确表示的最大项，再往后会丢失精度。

常见问题

为什么限制最大 78？

超过 2^53-1 的整数 JavaScript 无法精确表示，斐波那契第 79 项会溢出安全整数，工具因此限制输入为 0-78。

结果包含哪些内容？

输出第 n 项的值、F(n)/F(n-1) 的比值（n>0 时），以及从 F0 到 Fn 的完整前序数列。

黄金比例是精确值吗？

工具给出 10 位小数的比值，接近但不等同于黄金比例，可以理解为「项数越大之比越接近黄金比例」。
