#XML#格式化#校验

XML 格式化有什么用？

XML 文件常是单行压缩文本，难以阅读。格式化后按层级缩进，标签配对一目了然，还能同时校验标签是否闭合、属性是否合法。

支持哪些 XML 特性？

支持 XML 声明、注释、CDATA 段、自闭合标签、多级嵌套与缩进选择（2/4 空格），压缩模式会去除标签间的空白。

常见问题

格式化失败提示标签不匹配怎么办？

工具会指出期望的闭合标签和实际闭合标签，按提示修正对应行即可，常见于标签嵌套写反或漏闭合。

压缩模式会丢失内容吗？

不会，压缩只移除标签之间的空白字符，注释、CDATA、文本内容都会原样保留。

支持大文件吗？

支持，XML 会逐标签扫描并按结果输出，几十 MB 的文档也能处理，建议分批粘贴以免浏览器卡顿。

XML 数据安全吗？

所有处理都在浏览器本地完成，XML 内容不会上传到服务器。
