怎么选择字体搭配？

基本原则是标题字体与正文字体形成对比：衬线搭配无衬线、粗细对比、大小对比。本工具整理了 12 组经典搭配可直接参考。

网站字体怎么选？

优先选择系统字体与常用 Web 字体，加载快且兼容性好。本工具预览全部基于本地系统字体，所见即所得。

常见问题

可以在线使用这些字体吗？

预览使用本地系统字体。若引用 Google Fonts 需联网，本工具纯本地无需联网。

有哪些经典组合？

例如思源黑体+思源宋体、微软雅黑+Georgia、PingFang+SF Pro 等，工具内置多组。

怎么用在自己的项目里？

按预览组合在 CSS 中设置 font-family 即可，可复制预览文本中的组合代码。
