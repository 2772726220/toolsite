含税价和不含税价怎么换算？

不含税价 × (1+税率) = 含税价；含税价 ÷ (1+税率) = 不含税价。本工具自动完成并给出税额。

税率怎么选？

一般货物销售 13%，服务 6%，交通运输/建筑 9%，小规模 3%（优惠期 1%），可按需选择或自定义。

常见问题

结果保留几位？

默认保留 2 位小数，符合发票常见精度，税额可配置舍入方向。

价税合计是什么？

即含税总价 = 不含税价 + 增值税税额。

可以用作报税依据吗？

供参考，实际申报请以税务机关规定为准。
