什么是 Glassmorphism？

玻璃拟态是近年流行的 UI 风格：半透明背景 + 背景模糊 + 细边框 + 柔和阴影，让元素像磨砂玻璃一样通透又有层次。

怎么用生成的 CSS？

复制给出的卡片样式应用到你的 div 即可，背景需要放一张渐变或图片才有磨砂效果。

常见问题

兼容性如何？

使用了 backdrop-filter，现代 Chrome、Edge、Safari 支持，Firefox 103+ 支持，旧浏览器会退化为半透明不模糊。

可以商用吗？

生成的代码完全属于你，可自由使用。

为什么没有模糊效果？

backdrop-filter 需要有背景内容在元素后面，请确保容器背景是图片或渐变。
