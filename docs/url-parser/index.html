URL 由哪些部分组成？

完整 URL 包含协议、用户名密码、主机名、端口、路径、查询参数（Query）和锚点（Hash）。工具会自动拆分并标注端口是否为默认值。

为什么每个工具站点都要配 URL 解析？

排查回调地址、调试跳转、拼接分享链接时，快速看清参数归属能节省大量时间，尤其适合前端与爬虫开发者。

常见问题

支持哪些协议的 URL？

支持标准 http/https 以及 URL 标准中定义的所有 scheme，只要浏览器能解析即可。

查询参数会解析成什么？

会解析成独立的键值对列表，重复参数会一并列出，并展示 URL 编码后的原始查询字符串。

数据会上传吗？

不会，URL 解析完全在本地浏览器中完成。

端口显示默认是什么意思？

HTTPS 默认端口 443、HTTP 默认端口 80，省略端口时浏览器文件会使用默认值，工具会根据协议自动标注。
