TSV 是什么？

TSV（Tab-Separated Values）是用制表符分隔字段的表格文本，常从 Excel 等表格软件导出，第一行是表头。工具可把这类表格一键转成 JSON 对象数组。

TSV 转 JSON 时类型怎么处理？

首行作为键名，其余每行生成一个对象；纯数字（含小数）自动转成 number，true/false 转成布尔值，其余保留为字符串，可直接用于程序。

JSON 怎么转回 TSV？

把对象数组 JSON 粘贴进来，工具按对象中首次出现的键序生成表头，空值输出为空单元格，嵌套对象序列化为 JSON 字符串，可直接粘贴回 Excel 使用。

常见问题

支持带引号的字段吗？

支持。双引号包裹的字段会保留引号内内容，两个连续双引号作为转义也能正确解析，引号内的制表符不会误当作分隔符。

哪些 JSON 可以转 TSV？

必须是对象数组，如 [{"a":1},{"a":2}]；单个对象或标量会提示错误。

列顺序怎么确定？

按输入对象数组中各键首次出现的顺序生成表头，而不是字母序，保证与原数据一致。
