SHA 哈希是什么？

SHA 是安全哈希算法，把任意内容计算成固定长度的指纹（哈希值），同一内容结果永远一致，用于校验文件完整性。

这个工具能做什么？

计算文本或文件的 SHA-1、SHA-256、SHA-512 哈希值，可在下载文件后校验是否完整。

常见问题

SHA 是加密吗？

是单向哈希，不可逆，不是加密。常用于校验而非保密。

支持文件计算吗？

支持，选择文件即可计算其哈希值。

数据会上传吗？

不会，哈希在浏览器本地计算。

SHA-256 和 SHA-1 区别？

SHA-256 更安全，SHA-1 已不推荐用于安全场景。
