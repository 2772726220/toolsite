税后工资怎么算？

税后 = 税前 - 五险一金个人部分 - 个人所得税。个税按累计预扣法计算，专项附加扣除（房贷、赡养老人等）会减少应纳税额。

为什么要用工资计算器？

面试谈薪、跳槽比较、年度规划都需要知道实际到手多少，本工具帮你看清税前与税后的差距。

常见问题

计算准确吗？

按现行社保费率与个税起征点 5000 元/月计算，各地费率略有差异，结果供参考，以税务与社保官方为准。

支持专项附加扣除吗？

支持，可填写每月专项附加扣除金额，如房贷 1000 元、赡养老人 2000 元等。

公积金比例怎么选？

按你所在城市规定，一般 5%-12%，本工具默认 12% 可自行调整。
