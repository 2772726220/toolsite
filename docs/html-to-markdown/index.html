HTML 转 Markdown 怎么用？

直接粘贴 HTML 代码点击转换即可得到 Markdown 文本，支持字节前缀、复制结果，可保留 br 换行或忽略，链接可选行内式或引用式。

支持哪些 HTML 标签？

支持标题 h1-h6、段落、加粗/斜体/删除线、行内代码、链接、图片、无序/有序列表、引用、pre 代码块、水平线与换行，script/style 与注释自动剔除。

常见问题

能转换整张网页吗？

可以，转换时会自动剔除 script、style、注释与多余空白，把正文结构提取为 Markdown，适合博客搬迁、富文本文章转纯 Markdown。

表格为什么显示为文本？

表格内容会按单元格文本流输出，保留阅读信息；如需结构化表格可复制 HTML 使用转换型 Markdown 渲染器处理。

转换结果准确吗？

常见标签的转换结果与主流 Markdown 一致，嵌套列表与复杂表格建议转换后人工校对。

数据会上传吗？

不会，转换完全在浏览器本地完成。
