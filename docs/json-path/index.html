什么是 JSONPath？

JSONPath 是一种从 JSON 数据中定位和提取值的查询语言，类似 XML 的 XPath。例如 $.store.book[*].title 能取到所有书的标题，广泛用于接口数据提取和自动化测试。

支持哪些查询语法？

支持 .属性、['属性']、[0] 下标、[*] 通配、..递归查找所有层级的同名属性、[?(@.price<10)] 条件过滤，以及 ==、!=、<、>、<=、>=、=~ 等比较过滤器。

常见问题

输入格式有什么要求？

左侧粘贴标准 JSON 数据，右侧填写以 $ 开头的 JSONPath 表达式，点击查询即可看到匹配结果与数量统计。

怎么筛选价格低于 10 的商品？

使用过滤器表达式如 $.store.book[?(@.price<10)]，其中 @ 代表当前数组元素，支持的比较符有 ==、!=、<、>、<=、>= 和正则匹配 =~。

数据会泄露吗？

不会，JSONPath 查询完全在浏览器本地执行，数据不会上传到任何服务器。

支持递归查找吗？

支持，在属性名前加两个点如 $..price 会递归查找数据中所有层级的 price 属性，无论它嵌套多深。
