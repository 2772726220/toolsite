什么场景适合用文本模板？

给多名客户发相同措辞、内容不同的私信；生成周报/月报模板；按名单批量生成邀请函、工单、标签文案等，只要把变化的部分抽成占位符即可。

支持哪些占位符写法？

同时支持双花括号 {{name}} 与单花括号 {name}，键名不区分大小写，还可用 {{name|默认值}} 为缺失的键设置兜底内容。

常见问题

数据从哪里来？

可以直接粘贴 JSON（如 {"name": "张三"}），也可切换到「键值对」模式每行填 键=值，两种格式都支持。

缺失的变量会怎样？

模板中引用了但数据里没有的键会原样保留，并单独列出缺失键清单，方便排查。

会重复替换吗？

不会。同一个键在模板中出现多次时，每次都会替换为对应的值。
