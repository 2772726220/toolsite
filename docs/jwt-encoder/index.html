支持哪些算法？

对称: HS256/HS384/HS512; 非对称: RS256/RS384/RS512/ES256/ES384/ES512/PS256; 无签名: none。

私钥安全吗？

私钥仅在浏览器内存中用于签名，不上传、不存储，离开页面即销毁。

常见问题

能验证现有 Token 吗？

支持粘贴 Token 自动解码 Header/Payload/验证签名(需提供密钥/公钥)。

支持 JWK 吗？

支持粘贴 JWK Set 或单个 JWK 作为密钥来源。

能批量生成吗？

可配置不同声明批量生成多个 Token，便于测试权限/过期场景。

时钟偏移怎么处理？

可设置 nbf/exp/iat 的时间偏移，模拟过期/未生效场景。
