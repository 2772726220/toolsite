折旧表怎么算？

直线法每年折旧 = (原值 - 残值) ÷ 年限；双倍余额法按期初净值×2/年限递减且不低于残值；年数总和法按剩余年限占比分摊可折旧额。

双倍余额法和直线法有什么区别？

双倍余额法前几年折旧多、后几年少，能更快抵税；直线法每年平摊；年数总和法折旧逐年递减但前高后低，介于二者之间。

常见问题

残值可以设为零吗？

可以，残值设 0 表示资产报废后无残值，双倍余额法最后一年会把剩余净值全部折完。

用于报税可以吗？

可作参考估算，具体折旧年限与残值率以当地税法规定为准，正式报税请核对税务要求。

支持哪种计算方式最常用？

直线法最简单最常用；会计上很多企业为加速折旧会选用双倍余额法，工具内置三种可选。
