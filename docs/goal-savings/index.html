怎么使用？

填入目标金额、现有本金与年利率后：方式一输入每月存入金额，求需要几个月；方式二输入想用的月数，求每月需存多少。

利率怎么起作用？

利息按月复利计入，存款越早越多，利息收益越大；基准方案为每月月末存入（普通年金）。

常见问题

本金已超过目标怎么办？

工具会提示本金已达成目标，所需月数为 0。

利率 0 且不存入可能达成吗？

不能。此时余额不会增长，工具会给出提示。

结果是保证值吗？

不保证。利率会波动，结果为按固定利率粗略估算，仅供参考。
