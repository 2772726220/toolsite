什么是复数？

复数是形如 a+bi 的数，其中 i 是虚数单位，满足 i² = -1。复数让一元二次方程在实数范围外仍有解，在电路分析、信号处理等工程领域应用广泛。

复数怎么加减乘除？

加减是实部、虚部分别相加减；乘法按 (a+bi)(c+di) = (ac-bd) + (ad+bc)i 展开；除法 A÷B = A×B⁻¹，而 B 的倒数 B⁻¹ = (c-di)/(c²+d²)。工具的除法会同时展示共轭结果。

模和共轭是什么？

复数 z = a+bi 的模 |z| = √(a²+b²) 表示到原点的距离；共轭 z̄ = a-bi 实部相同、虚部取反，两者相乘恰为模的平方。工具每次计算都会附上模、共轭与倒数。

常见问题

支持哪种输入格式？

支持 3+4i、2-3i、纯虚数 i、-i、5i 以及纯实数 5 等常见形式，空格会被忽略后解析。

可以进行哪些运算？

下拉菜单提供 A+B、A-B、A×B、A÷B、A² 五种，输出运算结果的同时还会附上两个复数的模长、A 的共轭与倒数。

支持高次幂吗？

本工具目前只提供 A² 的幂入口，如需更高的整数次幂，可结合乘法结果连续计算。
