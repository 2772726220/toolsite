为什么需要 .gitignore？

node_modules、密钥文件、编译产物和系统杂项文件不该进 Git。用 .gitignore 忽略它们，仓库更干净、克隆更快、不出安全事故。

模板会不会过时？

模板来自官方 gitignore 生态的常用条目，覆盖主流语言、IDE 与操作系统，随时可用。

常见问题

多选模板会冲突吗？

不会，各部分按顺序拼接并带注释标题，重复条目也安全。

怎样应用到项目？

复制生成内容，粘贴到仓库根目录新建的 .gitignore 文件即可。

包含密钥文件吗？

「密钥与配置」模板会忽略 .env、*.pem 等常见敏感文件，强烈建议勾选。
