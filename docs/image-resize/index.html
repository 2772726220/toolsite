为什么要调整图片尺寸？

上传图片到平台常有尺寸限制，或需要缩小图片减小体积。本工具支持按百分比和指定宽度两种方式等比缩放。

缩放会失真吗？

缩小图片会丢失部分细节，放大图片会变模糊，这是正常现象。建议按实际需求选择合适的目标尺寸。

常见问题

图片会上传吗？

不会，缩放完全在浏览器本地完成。

支持哪些格式？

支持 JPG、PNG、WebP。

能放大吗？

可以放大，但超出原分辨率会变模糊。

会保留透明背景吗？

PNG 的透明通道会完整保留。
