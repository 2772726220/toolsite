#温度#换算

为什么要做温度换算？

出国旅行看天气预报、烘焙看国外菜谱、实验室记录数据，都会遇到摄氏/华氏/开尔文混用，换算器一键搞定。

三种温标有什么区别？

摄氏以水的冰点/沸点为 0/100 度，华氏以 32/212 度为冰点/沸点，开尔文是科学绝对温标，0K 为绝对零度。

常见问题

摄氏度怎么转华氏度？

华氏度 = 摄氏度 × 9/5 + 32。

开尔文和摄氏度什么关系？

K = ℃ + 273.15。

0 摄氏度是多少华氏度？

32 华氏度。

输入负温可以吗？

可以，任意数值都支持，仅开尔文不允许为负。
