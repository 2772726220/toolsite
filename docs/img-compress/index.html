图片为什么要压缩？

高分辨率图片动辄几 MB，上传到公众号、电商平台、聊天软件时常被压缩或直接失败。在线压缩图片可以大幅减小文件体积，让图片加载更快、存储更省、发送更顺畅。

压缩后会影响画质吗？

本工具采用智能压缩算法，可通过调节压缩质量滑块控制清晰度和文件大小的平衡。默认 70% 质量对人眼几乎无差别，但对上传速度的提升非常明显。PNG 图片建议选择 WebP 输出格式，体积通常可减小 60%-80%。

常见问题

在线图片压缩会影响图片质量吗？

会通过压缩算法减小文件体积。你可以手动调节压缩质量参数，在文件大小和清晰度之间找到平衡，视觉上几乎无差别。

我的图片会上传到服务器吗？

不会。本工具完全在您的浏览器本地运行，图片不会上传到任何服务器，隐私绝对安全。

一次可以压缩多少张图片？

支持多张批量压缩，一次性全部下载。建议每次不超过 20 张以保证流畅体验。

支持哪些图片格式？

支持 JPG/JPEG、PNG、WebP。PNG 选择 WebP 输出压缩效果最佳。
