宏量营养素怎么分配？

常见比例：均衡 30/40/30（蛋/碳/脂）、高蛋白 35/35/30、生酮 20/5/75、低碳 30/20/50。工具提供预设与自定义。

TDEE 是什么？

每日总能量消耗，含基础代谢 BMR + 活动系数。工具内置 Mifflin-St Jeor 公式自动算出。

常见问题

支持自定义比例吗？

支持，可手动输入蛋白质/碳水/脂肪百分比，总和需为 100%。

分餐建议怎么算？

按每日总宏量素均分到餐次（3-6 餐），可设置训练前后餐占比更高。

微量元素算吗？

当前版本仅宏量素（蛋/碳/脂/热量），微量元素建议参考膳食宝塔。

适合特殊人群吗？

孕妇、肾病、糖尿病等请遵医嘱，本工具仅供健康成人参考。
