月相周期多长？

一个朔望月约 29.53 天，从新月 → 上弦 → 满月 → 下弦 → 回到新月循环。

为什么会有误差？

本工具用简化天文模型近似计算，通常 ±1 天以内；精确观月建议结合天文年历核对。

常见问题

今天是满月吗？

把日期选为今天即可看到当天的月相、亮度与月亮年龄。

被照亮比例是怎么算的？

按月球相位角计算：新月约 0%，上/下弦约 50%，满月约 100%。
