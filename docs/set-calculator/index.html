集合运算工具：输入两个集合（元素用逗号或空格分隔），计算并集、交集、差集、对称差，或判断子集关系。

元素按字符串去重并保持首次出现顺序。显示 A−本次结果、B−本次结果、共有元素的数量划分。

集合运算有哪些？

并集 A∪B 是两者的全部元素；交集 A∩B 是共有元素；差集 A−B 是只在 A 的元素；对称差 A△B 是只在一边的元素。

怎么输入集合？

元素用逗号或空格分隔即可，如 「1, 2, 3」，重复元素自动去重，顺序按首次出现保持。

空集怎么显示？

结果集合为空时显示 ∅。

能否用中文元素？

可以。元素按字符串处理，中文、数字、字母均可。

子集判断怎么理解？

A⊆B 成立当且仅当 A 的每个元素都在 B 中（不含多余元素）；相等也算子集。
