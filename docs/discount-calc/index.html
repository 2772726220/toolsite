折扣价怎么算？

折后价 = 原价 × 折扣率。例如原价 200 元打 7.5 折，即 200 × 0.75 = 150 元。

满减怎么算？

满 X 减 Y 指消费满 X 元直接减 Y 元，可叠加多档，工具支持对比多种优惠方案哪样最划算。

常见问题

可以反向算折扣率吗？

可以，输入折后价与原价，自动算出折扣率（几折）。

满减和打折哪个划算？

工具会分别计算两种方案的实际支付金额并提示差异，帮你在结算时选最优。

支持多档满减吗？

支持，输入多个「满X减Y」档位，自动取最高可用的那一档。

需要联网吗？
