灰度化有什么用？

适合老照片复原、打印前去除彩色、突出光影层次、为设计稿统一色调，或作为后续处理的中间步骤。

强度参数是什么？

100% 为完全灰度，低于 100% 时按比例保留部分原色，得到偏淡的复古效果。

常见问题

会保留原图尺寸吗？

输出与原图同尺寸，格式默认 PNG。

支持透明背景吗？

支持，透明通道保留，仅对 RGB 通道做灰度处理。
