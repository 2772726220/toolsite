SQL 字符串为什么要转义？

SQL 中字符串用单引号包裹，字符串本身含单引号时需要写成两个单引号（''）转义，否则会破坏语句结构甚至引发注入风险。

适合哪些场景？

生成 IN (...) 条件列表、INSERT INTO ... VALUES、批量 UPDATE 等需要带引号的 SQL 片段，也方便把 Excel 数据转成 SQL。

常见问题

支持批量吗？

支持，每行一条，自动逐行加引号并用逗号连接，可直接粘贴进 IN 列表。

会转义引号内的引号吗？

会，所有单引号自动加倍（' 变成 ''），双引号与反斜杠按所选选项处理。

生成的内容安全吗？

工具仅做标准转义，建议拼接语句前仍使用参数化查询，这是防注入的最佳实践。

需要联网吗？

不需要，纯本地处理。
