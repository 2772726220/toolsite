怎么快速 AA？

输入总账单金额、小费百分比和人数，工具会算出一个总价并给出每人应付，还可把结果四舍五入到元方便转账。

小费怎么算？

小费按总金额百分比计算，可以自定义比例，也可以设为 0 表示不含小费。

常见问题

四舍五入后总账会变吗？

会略有差异，工具会同时显示精确分摊与四舍五入后的总金额，方便对比。

支持多人不同消费吗？

本工具按人均平摊计算，自定义分摊请使用普通计算器。
