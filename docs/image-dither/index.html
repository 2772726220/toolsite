对图片应用 Floyd–Steinberg 误差扩散抖动：把连续色调映射到少量颜色并保留明暗层次，做出像素风/艺术感。

图片仅在本机浏览器处理，不会上传。

广告位（AdSense / 优量汇横幅）

什么是抖动？

抖动通过把量化误差扩散到邻近像素，用少量颜色模拟出更多色调层次，是老式显示器与印刷中的经典技术，如今常用来做复古像素风。

支持几种调色板？

支持纯黑白、4 级灰度、8 色 VGA（黑/红/绿/蓝/黄/品/青/白）。

常见问题

图片会上传吗？

不会。处理全部在浏览器本地完成。

处理后的图会变小吗？

抖动后的像素值只有少数几种颜色，同尺寸下 PNG 体积通常会明显减小。

如何保存？

点击「下载 PNG」即可导出处理结果。
