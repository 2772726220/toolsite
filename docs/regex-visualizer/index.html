什么是正则铁轨图？

铁轨图用图形化路径展示正则匹配逻辑，每个节点代表状态，箭头代表转移，直观展示回溯、分支、量词行为。

怎么调试正则？

输入正则和测试文本，工具实时高亮匹配位置，铁轨图动画演示匹配路径，快速定位过度匹配/漏匹配。

常见问题

支持哪种正则语法？

基于 JavaScript 正则引擎（ECMAScript），兼容 PCRE 大部分常用语法。

铁轨图太复杂怎么办？

可折叠分组、隐藏非捕获组、仅显示匹配路径，简化视图。

支持替换预览吗？

支持，输入替换模板实时预览替换结果。

能导出图片吗？

支持导出 SVG/PNG，便于文档嵌入。
