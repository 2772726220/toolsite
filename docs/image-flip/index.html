翻转和旋转一样吗？

不一样。翻转（镜像）是沿着中轴对折，如左右镜像后文字会变成反字；旋转则是把画面整体转 90/180/270 度，不会翻转文字朝向。

适合哪些用途？

修正镜像拍摄的照片、制作对称图案灵感、素材镜像复用、避免对象指向页面边缘等图文排版的常见需求。

常见问题

会损失画质吗？

翻转只是像素重排，不改变内容信息，导出 PNG 为无损格式，画质不损失。

支持哪些输入格式？

浏览器能解码的常见图片格式都支持（JPG、PNG、WebP、BMP、GIF 等），输出统一为 PNG。

图片会传到哪里？

全程在浏览器本地处理，图片不会上传到任何服务器。
