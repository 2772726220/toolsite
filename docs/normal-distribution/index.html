Z 值概率怎么算？

Z 值对应的左侧累积概率 Φ(z) 用误差函数 erf 精确计算；右侧概率 = 1 - Φ(z)；标准正态分布均值 0 标准差 1。

概率反推 Z 值怎么算？

用二分法反解标准正态累积分布函数，得到满足 P(Z ≤ z) = p 的分位数，常用作 90%/95%/99% 置信区间临界值，如 ±1.645/±1.96/±2.576。

常见问题

±1σ ±2σ ±3σ 是多大区间？

正态分布中约 68.27% 数据落在 ±1σ、95.45% 落在 ±2σ、99.73% 落在 ±3σ，这是经验法则。

非标准正态怎么算面积？

给定均值 μ 与标准差 σ 时，先转标准分 z = (X-μ)/σ，再用标准正态累积分布函数求区间面积。

结果精度如何？

采用 erf 逼近公式与 200 次二分迭代，Φ(1.96)≈0.97500、分位数等关键值可达 5-6 位小数，足够教学与质检使用。
