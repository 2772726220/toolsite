Code128 是什么？

Code128 是高密度条码标准，支持全部 ASCII 字符，常用于物流与零售标签，本工具实现 Code 128B 编码与校验位。

怎么用生成的条码？

下载 SVG 或 PNG 后插入标签模板或打印，配合扫码枪即可读取。

常见问题

支持哪些字符？

支持 ASCII 可打印字符（32-126），即数字、字母与常用符号。

校验位会自动算吗？

会，Code128 校验位由编码计算，自动附加。

可以放大打印吗？

SVG 是矢量图，任意缩放不模糊，可直接用于打印。
