CSS filter 能做什么？

filter 属性可对元素应用亮度、对比度、饱和度、模糊、反色、色相旋转等视觉效果，常用于图片风格化、悬停特效和加载占位。

怎么使用生成的代码？

把复制到的 filter: ... 样式贴到元素的 CSS 上即可。注意 blur 等效果会创建新的层叠上下文。

常见问题

支持哪些滤镜？

支持 brightness、contrast、saturate、sepia、grayscale、invert、opacity、hue-rotate、blur 共 9 种常见滤镜组合。

生成的代码浏览器兼容吗？

filter 在现代浏览器全部支持；blur 对渲染开销略高，适中取值体验最佳。

为什么灰度的值很小？

如果对比度很低，灰度效果会被其它滤镜掩盖，建议先调高对比度再观察灰度效果。
